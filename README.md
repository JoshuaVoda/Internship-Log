# Internship Tracker PWA — v4

This version removes the Resume Bullets tab and keeps the app focused on:
- Daily Log
- Weekly Goals
- Friday Summary
- Stats

## How to update your GitHub Pages site
1. Unzip this folder.
2. Upload/replace all files in your GitHub repository.
3. Wait for GitHub Pages to redeploy.
4. Hard refresh your site:
   - Windows: Ctrl + Shift + R
   - Mac: Cmd + Shift + R

You should now see:
Daily Log | Weekly Goals | Friday Summary | Stats
